# CompClub

Лендинг компьютерного клуба: главный экран с 3D-кулером (three.js), три класса ПК с FPS, бронь места
на схеме зала, приватная комната, снек-бар.

Стек: Next.js 15, React 19, TypeScript, Tailwind CSS 4, shadcn, framer-motion, three.js.

## Запуск

```bash
npm install
npm run dev
```

Сборка и запуск в production-режиме:

```bash
npm run build
npm run start
```

## Что заменить перед запуском

- `src/lib/data.ts` — адрес, телефон, ссылки, цены бара и ориентировочные FPS.
- Бронь сейчас сохраняется только в браузере посетителя (`localStorage`), занятость мест имитируется.
  Её нужно подключить к серверу, CRM или боту.
- Фото взяты с Wikimedia Commons по свободным лицензиям, авторы перечислены в подвале сайта
  (`src/lib/credits.json`). Это не фото самого клуба — лучше заменить своими.
